## Экспериментальная beta: Fabric API 0.166.2

Встроенная версия Fabric API обновлена с 0.165.0 до **0.166.2+26.3**. Клиент всегда использует закреплённую копию и пропускает сторонние JAR Fabric API в папке `mods-java`; она проверяется по SHA-256 и при необходимости загружается из Maven Fabric. При первом запуске нужен интернет для зависимостей.

Чтобы обновиться: закройте старый лаунчер, распакуйте архив в новую папку и запустите лаунчер из него. Выберите нужный экземпляр Horizon, откройте «Главная → Моды» и нажмите «Импортировать клиент Java Bridge…»; выберите `horizon-client.exe` (или `horizon-client` на Linux) **из нового архива**. Дождитесь сообщения об импорте, включите Fabric и нажмите «Играть». Старый импортированный клиент автоматически не заменяется. Моды и миры не удаляйте; отдельно добавленный Fabric API из `mods-java` можно убрать — этот клиент его пропускает. Сделайте резервную копию миров.

Сборка экспериментальная, реальный Minecraft с Fabric 0.166.2 и модами не проверен. Обновление версии API не гарантирует совместимость модов и не устраняет само по себе зависание на проверке Minecraft-файлов при подготовке. Верхний каталог Modrinth к Fabric ещё не подключён.

Нужны собственные файлы Minecraft 26.3, совместимая подготовленная версия Horizon и JDK 25. Режим Fabric запускается без онлайн-проверки владения игрой; используйте свои файлы. Доверяйте только проверенным Java-модам — они имеют доступ к файлам и аккаунтам. Самообновление лаунчера отключено в сборке. Архивы не подписаны и не являются официальным релизом исходных проектов; SHA256SUMS.txt проверяет целостность, но не подлинность.
