## Экспериментальная сборка

Предварительный релиз объединяет офлайн-лаунчер этого репозитория и отдельный Java Bridge-клиент для Minecraft 26.3. Windows x64 и Linux x64: скачайте архив для своей системы и прочитайте `README-ru.txt` внутри.

**Это не проверенный рабочий релиз игры.** Сборка и автоматические тесты прошли, но запуск Minecraft и реального Fabric-мода не проверен. Интерфейсного переключателя Fabric пока нет: после импорта клиента он включается командой `play --fabric` из терминала. Сделайте резервную копию миров.

Потребуются собственные файлы Minecraft 26.3, совместимая подготовленная версия Horizon и JDK 25. При подготовке и первом запуске может понадобиться интернет для загрузки зависимостей Fabric. Игровые файлы Minecraft, Fabric и сторонние моды в архивы не включены. Режим Fabric явно запускается без онлайн-проверки владения игрой; используйте собственные файлы. Java-моды имеют полный доступ к файлам и аккаунтам — запускайте только доверенные моды.

Архивы **не подписаны**, не являются официальным релизом исходных проектов и не предназначены для механизма автоматических подписанных обновлений. `SHA256SUMS.txt` содержит контрольные суммы для проверки целостности, но сам по себе не подтверждает подлинность. Самообновление лаунчера в сборке выключено.

Архивы взяты из [успешной сборки GitHub Actions](https://github.com/shiilnurchik-tech/Horizon-Offline-Launcher-With-java-bridge/actions/runs/43737613557), созданной на коммите `909b9bcc6aa6f657bc7b431864d0efde73e63661`. Клиент Java Bridge собран из исходников `iaxivers/horizon-java-bridge` на коммите `99e8ba80497e0515909af4601a4b078020034d2c` с опубликованным в этом форке патчем явного офлайн-режима.
