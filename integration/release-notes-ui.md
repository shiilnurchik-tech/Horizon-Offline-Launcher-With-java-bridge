## Экспериментальная сборка с интерфейсом Fabric

Предварительный релиз объединяет офлайн-лаунчер и отдельный Java Bridge-клиент для Minecraft 26.3. Скачайте архив для Windows x64 или Linux x64, распакуйте и запустите **horizon-launcher**. Инструкция также находится в `README-ru.txt` внутри архива.

На вкладке **«Моды»** выбранного экземпляра Horizon доступны импорт клиента Java Bridge из архива, добавление и удаление Fabric JAR, открытие папки модов и переключатель Fabric. После импорта и включения переключателя используйте обычную кнопку «Играть». В обычной игре Fabric по умолчанию выключен. Другой экземпляр Minecraft: Java Edition использует собственный загрузчик и к этому режиму не относится.

**Это не проверенный рабочий релиз игры.** Сборка и автоматические тесты прошли, но запуск Minecraft, работа интерфейса на реальном компьютере и запуск реального Fabric-мода не проверены. Сделайте резервную копию миров.

Потребуются собственные файлы Minecraft 26.3, совместимая подготовленная версия Horizon и JDK 25. При подготовке и первом запуске может понадобиться интернет для загрузки зависимостей Fabric. Игровые файлы Minecraft, Fabric и сторонние моды в архивы не включены. Режим Fabric явно запускается без онлайн-проверки владения игрой; используйте собственные файлы. Java-моды имеют полный доступ к файлам и аккаунтам — запускайте только доверенные моды. Импортируйте только доверенный клиент из этого архива.

Архивы **не подписаны**, не являются официальным релизом исходных проектов и не предназначены для механизма автоматических подписанных обновлений. `SHA256SUMS.txt` содержит контрольные суммы для проверки целостности, но сам по себе не подтверждает подлинность. Самообновление лаунчера в сборке выключено.
