## Экспериментальная beta: свой Fabric API

Теперь Java Bridge использует Fabric API, который вы сами добавили в папку модов выбранного экземпляра через кнопку «Добавить моды Fabric…». JAR определяется по `fabric.mod.json`, а не по имени. Если своего API нет, используется проверяемая встроенная версия 0.166.2+26.3. Если добавлено несколько Fabric API, клиент сообщает об ошибке: оставьте только один JAR. Bridge компилирует свою платформу с выбранным API. Другие зависимости Fabric могут скачиваться через интернет.

Для обновления: закройте старый лаунчер, распакуйте архив в новую папку, запустите `horizon-launcher.exe` (Linux: `horizon-launcher`). Выберите нужный экземпляр Horizon → «Главная» → «Моды» → «Импортировать клиент Java Bridge…» и укажите `horizon-client.exe` (Linux: `horizon-client`) **из нового архива**. Старый импортированный клиент остаётся прежним, пока новый не импортирован. Затем добавьте нужный Fabric API как обычный Fabric-мод, включите Fabric и нажмите «Играть». Удалить лишние JAR можно в этом же списке или через «Открыть папку». Не удаляйте миры; сделайте резервную копию.

Автоматические тесты проверяют обнаружение своего API, отказ при дубликатах и распознавание отсутствия своего файла. Реальный запуск Minecraft с Fabric API и модами не проверен; установка собственной версии не гарантирует её совместимость. Обновление не исправляет само по себе зависание на этапе проверки игровых файлов. Каталог Modrinth пока не подключён к Bridge.

Нужны собственные файлы Minecraft 26.3, совместимая подготовленная версия Horizon и JDK 25. Режим Fabric запускается без онлайн-проверки владения игрой; используйте свои файлы. Java-моды и клиент имеют доступ к файлам и аккаунтам: используйте только доверенные программы. Самообновление лаунчера отключено в сборке. Архивы не подписаны и не являются официальным релизом исходных проектов; SHA256SUMS.txt проверяет целостность, но не подлинность.
