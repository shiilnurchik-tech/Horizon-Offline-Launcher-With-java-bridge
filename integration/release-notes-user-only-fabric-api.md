## Beta: только ваш Fabric API

В этом клиенте автоматическая подстановка Fabric API отключена: он использует только один JAR Fabric API из папки `mods-java` выбранного экземпляра. При запуске модов, если собственного Fabric API нет или добавлено несколько версий, клиент сообщает об ошибке. Файл распознаётся по `fabric.mod.json`, не по имени. Не подменяйте вручную файлы в служебном кэше; при запуске клиента он больше не загружает и не подставляет оттуда Fabric API. Для компиляции платформы используется тот же JAR, который выбрал пользователь. Другие зависимости, включая Fabric Loader, могут загружаться через интернет.

**Как включить:** закройте старый лаунчер, распакуйте новый архив в отдельную папку и запустите `horizon-launcher.exe` (Linux: `horizon-launcher`). Выберите экземпляр Horizon, откройте «Главная → Моды» → «Импортировать клиент Java Bridge…» и выберите `horizon-client.exe` (Linux: `horizon-client`) **из этого нового архива**. Импорт обязателен: старые импортированные клиенты не изменяются автоматически. Убедитесь, что в «Моды Fabric» добавлен ровно один ваш Fabric API для Minecraft 26.3; лишние версии удалите в интерфейсе. Включите Fabric и нажмите «Играть». Не удаляйте миры, сделайте их резервную копию.

Сборка экспериментальная: выбор своего API и случаи отсутствия/дубликатов проверяются автоматическими тестами, но реальный запуск Minecraft и модов не проверен. Совместимость API и модов с Bridge не гарантируется. Эта сборка не исправляет отдельно зависание на этапе проверки Minecraft-файлов и не подключает каталог Modrinth к Bridge.

Нужны собственные файлы Minecraft 26.3, совместимая подготовленная версия Horizon и JDK 25. Режим Fabric запускается без онлайн-проверки владения игрой; используйте свои файлы. Java-моды и клиент получают доступ к файлам и аккаунтам — запускайте только доверенные программы. Самообновление лаунчера отключено. Архивы не подписаны и не являются официальным релизом исходных проектов; SHA256SUMS.txt проверяет целостность, но не подтверждает подлинность.
