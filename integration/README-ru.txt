Horizon Offline + Java Bridge — экспериментальная сборка

Это два совместно собранных исполняемых файла: офлайн-лаунчер этого репозитория
и отдельный клиент Java Bridge, взятый из iaxivers/horizon-java-bridge (коммит
99e8ba80497e0515909af4601a4b078020034d2c) и изменённый для явного офлайн-запуска.
Запуск Minecraft и реальных модов в этой сборке пока не проверен. Сделайте
резервную копию миров: модифицированные миры могут не открываться без модов.

1. Установите через лаунчер совместимую версию Horizon для Minecraft 26.3 и
   подготовьте её из своих файлов Minecraft. Minecraft, ресурсы и моды в этот
   архив не входят. Подготовка может потребовать соединения с интернетом.
2. Установите JDK 25 (нужен javac, а не только Java Runtime). При необходимости
   задайте HORIZON_JAVA_HOME как папку JDK. При первом запуске Fabric Loader,
   Fabric API 0.166.2+26.3 и их библиотеки могут скачиваться из интернета.
   Клиент использует свою закреплённую версию Fabric API и пропускает другие
   версии API в папке модов; оставьте там только обычные моды.
3. В окне лаунчера выберите нужный экземпляр Horizon и откройте вкладку «Моды».
   В разделе «Моды Fabric» нажмите «Импортировать клиент Java Bridge» и выберите
   horizon-client.exe (на Linux — horizon-client) из этого архива. Импортирует
   только доверенный файл: клиент, как любая программа, получает доступ к компьютеру.
4. Добавьте свои JAR-файлы кнопкой «Добавить моды Fabric», включите переключатель
   Fabric и нажмите «Играть». В интерфейсе можно открыть папку и удалить моды.

Импортированный клиент использует игровые файлы установленной версии. Убедитесь,
что выбран именно клиент из этого архива и подготовлены его игровые файлы.
Выключенный переключатель не передаёт флаги Java Bridge в игру; включённый
специально выбирает офлайн-режим без проверки владения через Microsoft. Это не
разработческий HORIZON_JAVA_MODS и не меняет обычный вход; используйте свои файлы.
Java-моды являются программами с полным доступом к вашим файлам и аккаунтам:
запускайте только моды, которым доверяете.

Самостоятельное обновление лаунчера в этой сборке выключено; артефакты Actions
не подписаны и не являются официальным релизом. По-прежнему доступны команды
java-mods и play --fabric для тех, кто предпочитает терминал.
