Horizon Offline + Java Bridge — экспериментальная сборка

Это два совместно собранных исполняемых файла: офлайн-лаунчер этого репозитория
и отдельный клиент Java Bridge, взятый из iaxivers/horizon-java-bridge (коммит
99e8ba80497e0515909af4601a4b078020034d2c) и изменённый для явного офлайн-запуска.
Запуск Minecraft и реальных модов в этой сборке пока не проверен. Сделайте
резервную копию миров: модифицированные миры могут не открываться без модов.

1. Установите через лаунчер совместимую версию Horizon для Minecraft 26.3 и
   подготовьте её из своих файлов Minecraft. Minecraft, ресурсы и моды в этот
   архив не входят. Подготовка может потребовать соединения с интернетом.
2. Установите JDK 25 (нужен javac, а не только Java Runtime). При необходимости
   задайте HORIZON_JAVA_HOME как папку JDK. При первом запуске Fabric Loader,
   Fabric API и их библиотеки могут скачиваться из интернета.
3. В терминале, в этой папке (на Windows используйте horizon-launcher.exe):

   ./horizon-launcher import-build ./horizon-client --trust-unsigned
   ./horizon-launcher java-mods add /путь/к/моду.jar
   ./horizon-launcher play --fabric

Команда import-build выберет импортированный клиент и использует игровые файлы
установленной версии. Дополнительно можно указать --version <тег>. Убедитесь,
что выбран именно клиент из этого архива и подготовлены его игровые файлы.
Без --fabric игра запускается без Java-модов. --fabric специально включает
офлайн-режим без проверки владения через Microsoft. Это не разработческий
HORIZON_JAVA_MODS и не меняет обычный вход; используйте свои игровые файлы.
Java-моды являются программами с полным доступом к вашим файлам и аккаунтам:
запускайте только моды, которым доверяете.

Самостоятельное обновление лаунчера в этой сборке выключено; артефакты Actions
не подписаны и не являются официальным релизом. UI-переключателя Fabric пока
нет: команда play --fabric запускается из терминала.
